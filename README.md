# Modern C++ Algorithms Workshop
Refactoring legacy loops into clean, expressive standard algorithms

## Goal

These exercises train your ability to replace raw loops with the correct standard algorithm (`std::find_if`, `std::count_if`, `std::accumulate`, `std::sort`, `std::partition`, `std::unique`, etc.).

Each exercise includes:

- some legacy code  
- unit tests (GoogleTest)  
- a TODO telling you which algorithm you should consider  
- a link to run it directly on Compiler Explorer  

## Quick start

1. Pick any exercise below.  
2. Open the CE link.  
3. Refactor the function to use the right algorithm.  
4. Press "Run". All tests must pass.  
5. Commit your working solution locally if you want to keep a record.
